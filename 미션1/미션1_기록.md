# 미션 1 기록

* AI A 이름 / 대화 공유 링크 또는 캡처 파일명: ChatGPT (6.1 Sol) / 영화\_A\_Chatgpt.pdf (대화 전체를 PDF로 저장. 공유 링크는 조직 계정이라 외부에서 열리지 않을 수 있어 PDF로 대신함)
* AI B 이름 / 대화 공유 링크 또는 캡처 파일명: Claude (Sonnet 5.5) / 영화\_B\_Claude.pdf (공유 화면을 PDF로 저장, 실명은 ○○○로 가림)
  * 진행 순서 메모: B에는 새 대화에 기획서.md를 먼저 첨부했는데 Claude가 바로 HTML을 만들었고, 이어서 3)번 요청 3줄을 보내자 "이미 전달했다"고 답함. A(ChatGPT)는 같은 대화에서 질문→기획서→3줄 요청 순서로 만듦
* AI가 물어서 내가 정한 것:

  * 누가 쓰나: 나 혼자 정하고, 친구에게는 내 컴퓨터 화면으로 직접 보여 줌
  * 목적: 내 영화 취향을 한눈에 보여 주기 (서로 비교·추천·함께 순위 정하기는 '혼자 정함'과 맞지 않아 제외)
  * 기기: 컴퓨터 (마우스 끌어 놓기가 잘 되고, PC에서 바로 확인할 수 있어서)
  * 등급: S·A·B·C·D 5단계
  * 영화 표시: 제목만 (포스터는 외부 이미지가 필요해 HTML 한 장 조건과 맞지 않아 제외)
  * 옮기는 방법: 마우스로 끌어서 놓기
  * 영화 목록: 8편으로 시작, 제목 추가·삭제 가능
  * 다시 열기: 같은 컴퓨터·브라우저에서 자동 복원
  * 보여 주는 방법: 내 화면으로 직접 (이미지 저장·웹 주소 공유는 외부 라이브러리·호스팅이 필요해 제외)
  * 화면 분위기: 어두운 배경에 등급별 색상
  * AI가 미정으로 남긴 4가지(분위기, 같은 등급 안 순서, 첫 실행 배치, '처음으로' 때 추가 영화 처리)를 직접 정해 기획서에 반영함
* 같은 행동으로 비교한 결과(해본 행동 → 기대 결과 → A의 결과 / B의 결과):

  * '기생충'을 S칸으로 끌어 놓기 → S칸에 표시 → A 됨 / B 됨
  * S의 '기생충'을 B칸으로 옮기기 → B칸에만 있음 → A 됨 / B 됨
  * '테스트 영화' 추가 후 삭제 → 생겼다가 사라짐 → A 초안: 처음 확인할 때 추가 안 됨, 수정본 됨 / B 됨
  * 한글 제목 입력 후 Enter → 카드 하나만 생김 → A 됨 / B 됨
  * 등급을 바꾸고 새로고침·다시 열기 → 배치 유지 → A 됨 / B 됨
  * '처음으로' 누르기 → 추가 영화 삭제, 8편 모두 미분류 → A 됨 / B 됨
  * 공백만 넣고 추가 → 카드 안 생기고 안내 → A 됨 / B 됨
  * 화면 → A: 안내·편수·저장 상태 표시가 많고 스크롤해야 미분류가 보임 / B: 간결하고 한 화면에 모두 보임
* 선택한 파일명과 고른 이유: 영화\_B\_초안.html — 두 파일 모두 완성 기준을 통과했고, B는 등급표와 미분류가 한 화면에 다 보여 친구에게 화면으로 보여 준다는 목적에 더 맞아서
