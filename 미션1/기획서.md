# 영화 티어리스트 웹페이지 기획서

## 1. 누가 쓰나

- 영화 등급을 정하고 수정하는 사람은 나 혼자다.
- 친구들에게 내 컴퓨터 화면을 직접 보여준다.
- 주 사용 기기는 컴퓨터다.

## 2. 무엇을 하려고

내가 본 영화를 **S · A · B · C · D 다섯 등급**으로 나누어, 내 영화 취향을 한눈에 보여주고 친구들과 영화 이야기를 나누려고 한다.

## 3. 화면과 동작

| 항목 | 정한 내용 |
| --- | --- |
| 화면 | 어두운 배경에 등급별 색상으로 구분 |
| 등급 | S · A · B · C · D의 5단계 |
| 영화 표시 | 영화 제목만 표시 |
| 첫 실행 | 저장된 배치가 없는 첫 실행에는 처음 영화 8편을 모두 미분류에 표시 |
| 영화 이동 | 마우스로 영화를 끌어서 원하는 등급에 놓기 |
| 같은 등급 안의 순서 | 순서 지정 기능을 넣지 않음 |
| 영화 관리 | 영화 제목을 직접 입력하여 추가하거나 삭제 |
| 입력 안내 | 제목이 비어 있거나 공백뿐이면 카드를 만들지 않고 입력 안내 표시 |
| 저장과 복원 | 같은 컴퓨터·브라우저에서 다시 열면 영화 배치를 자동 복원 |
| 처음으로 버튼 | 추가한 영화를 삭제하고, 처음 영화 8편만 모두 미분류로 복원 |
| 실행 방식 | 외부 파일·로그인·서버 없이 HTML 파일 하나를 더블클릭하여 실행 |

앞서 미정으로 남겼던 네 항목은 모두 위 내용으로 확정한다.

## 4. 필요한 자료

화면에 사용할 자료는 영화 제목이며, 시작할 영화 목록은 다음 8편이다.

1. 기생충
2. 인터스텔라
3. 라라랜드
4. 센과 치히로의 행방불명
5. 어벤져스: 엔드게임
6. 범죄도시
7. 타이타닉
8. 토이 스토리

추가할 영화는 사용자가 제목을 직접 입력한다.

## 5. 완성 기준

제작 후 아래 문장을 직접 확인한다.

- [ ] 컴퓨터에서 페이지를 열면 어두운 배경에 S · A · B · C · D 다섯 등급이 색상으로 구분되고, 미분류 영역도 보인다.
- [ ] 저장된 배치가 없는 첫 실행에는 처음 제공한 영화 8편이 모두 미분류에 표시된다.
- [ ] ‘기생충’을 마우스로 끌어 S 등급에 놓으면 S 영역에 표시된다.
- [ ] S에 놓은 ‘기생충’을 B로 옮기면 B에만 표시되고 S에는 남아 있지 않다.
- [ ] 확인용 제목인 ‘테스트 영화’를 추가하면 화면에 나타나고, 삭제하면 목록에서 사라진다.
- [ ] 영화 여러 편의 등급을 바꾼 뒤 새로고침해도 배치가 그대로 남아 있다.
- [ ] 페이지를 닫았다가 같은 컴퓨터·브라우저에서 다시 열어도 영화 배치가 그대로 남아 있다.
- [ ] 영화를 추가하고 기존 영화들을 여러 등급에 배치한 뒤 ‘처음으로’를 누르면, 추가한 영화는 사라지고 처음 8편만 모두 미분류에 표시된다.
- [ ] ‘처음으로’를 누른 뒤 페이지를 닫았다 다시 열어도 처음 8편만 미분류에 남아 있다.
- [ ] 제목 칸을 비우거나 공백만 넣고 추가를 누르면 카드가 생기지 않고 입력 안내가 나온다.
- [ ] 외부 파일·로그인·서버 없이 HTML 파일 하나를 더블클릭하면 열린다.
