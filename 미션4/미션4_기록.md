# 미션 4 기록

- 사용한 AI 이름 / 주요 대화 캡처 파일명: ChatGPT (6.1 Sol) / ChatGPT_대화기록_기능추가.pdf (영화_원본.html과 기획서.md를 첨부해 기능을 요청한 메시지와 AI의 답)
- 더한 기능과 고른 이유: 칸마다 영화 개수 보여 주기. 영화를 옮기거나 추가할 때마다 숫자가 바로 바뀌어야 해서, 숫자와 실제 카드 수를 비교하면 새 기능이 맞는지와 원래 기능(옮기기·추가·저장·처음으로)이 그대로 되는지를 한 번에 확인할 수 있기 때문
- 기획서에 덧붙인 완성 기준 (요청 전에 먼저 씀):
  - S·A·B·C 칸과 아직 안 정한 영화 칸마다 들어 있는 영화 개수가 보입니다.
  - 영화를 옮기거나, 추가하거나, '처음으로'를 누르거나, 다시 열면 칸마다 보이는 숫자가 실제 카드 수와 같게 바로 바뀝니다. (처음 열거나 '처음으로'를 누르면 S·A·B·C 0개, 미분류 8개)

| 받은 파일 | 맞지 않은 완성 기준 | 한 일 (고치기 / 원래 파일로 돌아가기 / 완성) |
|---|---|---|
| 영화_기능추가.html | 없음. '처음으로' 후 완성 기준 9개를 처음부터 해 봄: 처음 S·A·B·C 0개·미분류 8개 / 기생충 S로 → S 1개·미분류 7개 / 라라랜드 누르고 A → A 1개 / 기생충 S→B → S 0개·B 1개 / '아이언 맨' 추가 → 미분류 늘어남 / 빈 제목 추가 → 카드 안 생기고 숫자 그대로 / F5 → 배치·숫자 그대로 / '처음으로' → 0개·8개, 아이언 맨 사라짐 / 폭 400에서 버튼·숫자 모두 보임 / 더블클릭으로 열림 | 완성 (영화_기능추가.html이 완성본) |

- 원래 기능이 망가지지 않아 원래 파일로 돌아가는 단계는 건너뜀. 원본(영화_원본.html)과 받은 파일을 비교해 보니 개수를 세어 보여 주는 부분만 더해졌고, 옮기기·추가·저장·처음으로 부분은 그대로였음
- AI는 "실제 브라우저 화면 검증은 환경 제한으로 수행하지 못했다"고 답함 → 그래서 브라우저에서 직접 완성 기준을 처음부터 다 해 봄
- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유: 완성 기준을 '숫자가 보인다'만 쓰지 않고 '언제 바뀌어야 하는지'까지 미리 써 둔 덕분에, 숫자가 보이기만 하는지 실제로 맞는지 확인할 수 있었음. 동료들은 새 기능의 완성 기준을 어떤 행동과 결과로 썼는지 비교해 보고 싶어서
