# 미션1-3 2단계 — 받은 피드백 하나씩 직접 확인

규칙: AI 말도 동료 말도 **직접 해 보기 전엔 믿지 않기**. 시작 전 '처음으로' 누르기.
결과 칸에 "어떻게 했더니 → 어떻게 됐다"를 짧게 적기.

## AI 검토 3가지

| # | 받은 의견 | 직접 해 볼 행동 | 결과 | 맞음/틀림 |
|:-:|---|---|---|:-:|
| A1 | 저장 기능이 없어 다시 열면 모두 미분류 | (1단계에서 이미 해 봄) | | |
| A2 | '처음으로'가 직접 추가한 영화를 지우지 않는다 | 영화 1편 추가 → '처음으로' → 추가한 영화가 남는지 보기 | | |
| A3 | 빈 제목을 막지 않아 **기획서를 어긴다** | 빈칸 추가는 1단계에서 해 봄 → **기획서에 빈 제목 이야기가 있는지** 찾아보기 | | |

|:-:|---|---|---|:-:|
