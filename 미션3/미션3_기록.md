|---|---|---|---|
| AI 1. 저장 기능이 없어 다시 열면 모두 미분류로 돌아간다 | 몇 편 옮기고 F5를 누르니 모두 미분류로 돌아감 | 반영 | 직접 해 보니 그렇고, 완성 기준 '같은 파일을 다시 열어도 영화와 등급이 남습니다'를 지키지 못함 |
| AI 2. '처음으로'가 직접 추가한 영화를 지우지 않는다 | 영화 1편을 추가하고 '처음으로'를 누르니 추가한 영화가 사라지고 8편만 미분류로 돌아감 | 보류 | 직접 해 보니 AI 말과 다름. 기획서대로 처음 목록과 배치로 잘 돌아감 |
| AI 3. 빈 제목을 막지 않아 기획서를 어긴다 | 제목 칸을 비우고 '추가'를 누르니 글자 없는 빈 카드가 생김. 그러나 기획서에는 빈 제목에 대한 내용이 없음 | 보류 | 빈 카드가 생기는 것은 맞지만 '기획서를 어긴다'는 판단은 틀림. 기획서 위반이 아니라 쓰다가 이상했던 점으로 따로 제안함 |
| 동료 1. 등급마다 색이 달라 한눈에 들어온다 (좋은 점) | S·A·B·C 칸 왼쪽 글자 칸 색이 서로 달라 구분됨 | 반영 (그대로 유지) | 직접 봐도 그렇고, 등급을 나눈다는 목적에 도움이 됨 |
| 동료 2. '8편 중 3편 나눔' 표시가 좋다 (좋은 점) | 영화를 옮기니 나눈 편수가 바로 바뀜 | 반영 (그대로 유지) | 직접 해 보니 그렇고, 얼마나 남았는지 알 수 있음 |
| 동료 3. 끌 때 칸 색이 바뀐다 (좋은 점) | 카드를 칸 위로 끌고 가니 칸 배경색이 살짝 바뀜 | 반영 (그대로 유지) | 직접 해 보니 그렇고, 어디에 놓일지 알 수 있음 |
| 동료 4. 휴대폰으로 열어 보니 좀 불편했다 | 휴대폰 폭(약 480px)으로 보니 '추가'·'처음으로' 버튼과 '8편 중 0편 나눔'이 잘리고 가로로 밀어 볼 수도 없음 | 되묻기 | 무엇이 불편했는지 적혀 있지 않아 같은 문제인지 알 수 없음. "휴대폰에서 어떤 화면을 보고 무엇을 하려다 불편하셨나요? 버튼이 안 보였나요, 아니면 글자·카드가 작았나요?" |
| 동료 5. 카드 옮기는 게 처음엔 좀 헷갈렸다 | 카드 누르고 등급 글자 누르기, 끌어 놓기 모두 잘 됨 | 되묻기 | 어느 부분에서 헷갈렸는지 알 수 없음. "누르는 방법과 끄는 방법 중 어느 쪽이, 어떤 순간에 헷갈리셨나요?" |
| 동료 6. 안 정한 영화가 맨 아래라 끌고 올라가기 불편하다. 목록이 위나 옆에 있으면 좋겠다 | 맨 아래 카드를 S칸까지 끌어 올리려면 화면을 같이 올려야 함. 나도 페이지가 두 화면 길이라 불편했음 | 보류 | 불편한 것은 맞지만, 기획서가 '위에 S·A·B·C 칸, 아래에 아직 안 정한 영화'로 정해 둠. 끌기 대신 '카드 누르고 등급 글자 누르기'로도 옮길 수 있음 |
| 동료 7. 카드 색이 좀 칙칙하다 | 카드가 회색 계열인 것은 맞음 | 보류 | 기획서에 색 조건이 없고 취향의 문제라 꼭 바꿀 이유가 없음 |
| 동료 8. 영화 포스터 사진이 나오면 좋겠다 | 지금은 제목 글자만 나옴 | 보류 | 완성 기준 '외부 파일이나 로그인 없이 HTML 한 장으로 열립니다'와 부딪힘 |
| 동료 9. C칸은 없어도 될 것 같다 | S·A·B·C 네 칸이 있음 | 보류 | 기획서 목적이 'S·A·B·C 등급으로 나누어 내 취향 정리'라서 C칸을 빼면 목적과 맞지 않음 |
| 동료 10. 큰 문제 없어 PASS | 직접 해 보니 완성 기준 6개 중 2개(다시 열기, 좁은 화면)가 안 됨 | 보류 | 완성 기준을 지키지 못한 것이 있어 '큰 문제 없음'이라고 보기 어려움 |

- 아무도 말하지 않았는데 내가 찾은 것:
  - 화면 폭이 좁아지면 오른쪽이 잘림 (완성 기준 4번). 휴대폰 폭에서 '추가'·'처음으로' 버튼과 '8편 중 0편 나눔' 표시가 잘려 안 보이고, 가로로 밀어 볼 수도 없음. AI는 "세 가지 외에는 완성 기준을 잘 지킨다"고 했고, 동료는 "휴대폰이 좀 불편"이라고만 해서 무엇이 문제인지 드러나지 않았음
  - 창을 조금 줄였을 때는 괜찮아 보였는데, 휴대폰 폭까지 줄여야 잘리는 것이 보였음 → 완성 기준은 끝까지 해 봐야 확인됨
- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유: AI 검토가 3개 중 2개를 틀렸고(처음으로·빈 제목), 실제로 안 되는 '좁은 화면'은 놓쳤음. 동료도 PASS를 줬음. AI나 동료 말을 그대로 믿지 않고 직접 해 봐야 하는 이유를 동료들은 어떤 경험으로 느꼈는지 나눠 보고 싶어서
