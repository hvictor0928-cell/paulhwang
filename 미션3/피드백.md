# 민수 님께 드리는 피드백

잘된 점: 카드를 누르고 등급 글자를 누르는 방법과 끌어 놓는 방법이 모두 잘 됩니다. 끌 때 칸 색이 바뀌어 어디에 놓일지 알 수 있습니다. 등급마다 색이 달라 한눈에 구분되고, 위쪽의 '8편 중 3편 나눔' 표시로 남은 영화를 알 수 있어 좋았습니다. '처음으로'를 누르면 직접 추가한 영화까지 지워지고 처음 8편이 모두 미분류로 돌아갑니다. 기획서대로입니다.

고치면 좋을 점

1. 본 것: 영화 몇 편을 등급 칸으로 옮긴 뒤 F5(새로고침)를 눌렀더니 모든 영화가 미분류로 돌아갔습니다.
기준: 기획서 완성 기준 '같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다'
제안: 옮길 때마다 브라우저에 배치를 저장해 두고, 다시 열면 저장된 배치를 불러오면 좋겠습니다.

2. 본 것: 브라우저 폭을 휴대폰 정도(약 480px)로 좁혔더니 제목 칸 오른쪽의 '추가'·'처음으로' 버튼과 위쪽 '8편 중 0편 나눔' 표시가 잘려 보이지 않았습니다. 가로로 밀어 볼 수도 없었습니다.
기준: 기획서 완성 기준 '화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다'
제안: 페이지 폭을 고정하지 말고 화면 폭에 맞춰 줄어들게 하고, 좁은 화면에서는 버튼이 입력 칸 아래 줄로 내려오면 좋겠습니다.

3. 본 것: 제목 칸을 비운 채 '추가'를 눌렀더니 글자 없는 빈 카드가 '아직 안 정한 영화'에 생겼습니다.
기준: 기획서에는 없지만 쓰다가 이상했던 점 (어떤 영화인지 알 수 없는 카드가 남음)
제안: 제목이 비어 있으면 카드를 만들지 않고 "제목을 입력해 주세요" 같은 안내를 보여 주면 좋겠습니다.
