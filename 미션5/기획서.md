# 명동성당 3D 기도 공간

기획 단계의 문서다. 사용자가 제공한 온라인 사찰 프롬프트 이미지를 참고해, 작은 인물이 성당 마당과 내부를 둘러보고 기도하는 공간으로 구성한다. 대화에서 정한 내용과 화면 구성·필수 기능·완료 기준·한계 및 비목표·검증 방법은 **확정**, 추가 기능은 **선택 제안**으로 표시한다. (수정)

## 대상 사용자

- **확정:** 천주교 신자와 비신자를 포함한 누구나.
- 컴퓨터와 휴대전화에서 잠시 쉬거나 기도하고 싶은 사람.
- 종교 지식이나 게임 조작 경험이 없는 사람도 사용할 수 있도록 설명과 버튼을 간단하게 제공한다.

## 사용 목적

- **확정:** 일상에서 잠시 마음을 가라앉히고 기도하는 시간을 제공한다.
- 성당에 들어가 머무는 경험을 통해 비신자가 천주교에 자연스럽게 관심을 갖도록 돕는다.
- 요청자 바오로님의 구상을 반영하되, 화면 속 인물은 이름과 얼굴 묘사가 없는 일반적인 신자로 표현한다.
- 첨부 예시의 작은 인물, 공간 탐색, 기도 동작, 차분한 분위기를 성당에 맞게 적용한다.

## 화면 구성과 동작

### 확정한 방향

- **3D 공간:** 최신 요청에 따라 평면 그림 중심에서 3D 성당 공간으로 구체화한다. 성당과 인물은 코드로 새로 만들며 사진·동영상 파일을 사용하지 않는다.
- **시점:** 보는 사람이 작은 인물의 모습을 지켜보는 3인칭 시점이다.
- **자동 입장:** 성당 바깥 → 문 열림 → 중앙 통로 걷기 → 무릎 꿇고 기도 순서로 약 1분 동안 자동 진행한다.
- **마지막 화면:** 기도 자세와 천주교 공식 기도문 ‘주님의 기도’ 전문을 계속 표시한다. (수정) 기도 장면은 자동 반복하지 않는다. (수정)
- **실행:** 컴퓨터와 휴대전화에서 HTML 파일 하나로 실행하며 로그인·API 키·서버를 요구하지 않는다. 외부 자료를 불러오지 않아 인터넷 없이도 실행하도록 한다.

### 공간·화면 구성 확정 (수정)

| 영역 | 구성 | 사용자가 하는 일 |
| --- | --- | --- |
| 성당 마당 | 성당 외관, 출입문, 길, 나무·화단, 작은 신자 인물, 돌로 쌓은 동굴 모양 안에 선 성모님상과 그 앞의 꽃(루르드 성모 동굴 형태) (수정) | 성당을 바라보거나 입구로 이동한다. |
| 성당 입구 | 인물이 접근하면 열리는 문, 외부와 내부가 이어지는 통로 | 문을 지나 내부로 들어간다. |
| 중앙 통로 | 좌우 의자, 기둥·아치, 색유리(스테인드글라스) 창, 끝에 보이는 제대 (수정) | 통로와 의자 옆의 이동 가능한 구역을 둘러본다. |
| 기도 공간 | 제대가 보이는 자리, 무릎 꿇는 인물, 주님의 기도 전문, 제대 뒤 벽의 예수님상이 달린 십자가(십자고상), 제대 옆 성모님상, 제대 양옆 촛대 (수정) | ‘기도하기’를 누르고 조용히 머문다. |
| 화면 위쪽 | 제목, 현재 위치, ‘조작 안내’, ‘처음으로’, ‘소리 켜기/끄기’ 버튼 (수정) | 위치와 조작법을 확인하거나 시작 화면으로 돌아간다. 소리 버튼으로 배경음악과 낭독을 켜거나 끈다. (수정) |
| 화면 아래쪽 | 필요한 행동 버튼과 짧은 조작 안내, 휴대전화용 이동 조작부 | 이동·기도·일어서기를 선택한다. |

따뜻하고 은은한 조명, 부드러운 그림자, 차분한 색상을 사용하는 것으로 확정한다. (수정) 공간을 넓게 보여 주고, 화면에 항상 떠 있는 설명은 최소화한다. ‘명동성당에서 영감을 받아 만든 가상 공간’임을 안내한다.

### 세부 동작 확정 (수정)

**1. 처음 열었을 때**

성당 마당과 인물을 보여 준다. ‘성당으로 들어가기’와 ‘직접 둘러보기’ 두 가지 시작 방법을 제공한다. 별도의 설정이나 회원가입은 없다.

**2. 자동으로 들어가기**

‘성당으로 들어가기’를 누르면 카메라가 인물을 따라가며 아래 순서로 진행한다. 단계별 시간 배분은 확정이다. (수정)

| 시작 후 시간 | 인물과 공간의 동작 |
| --- | --- |
| 0~10초 | 성당 바깥에서 입구를 향해 천천히 걷는다. |
| 10~20초 | 출입문이 열리고 내부로 들어간다. |
| 20~50초 | 중앙 통로를 따라 제대 방향으로 걷는다. |
| 50~60초 | 기도할 자리에 멈춰 무릎을 꿇는다. |
| 약 60초 이후 | 기도문을 표시하고 자세를 유지한다. 사용자가 조작할 때까지 끝 장면에 머문다. |

진행 중 ‘직접 둘러보기’를 선택하면 자동 이동을 멈추고 현재 위치에서 자유 이동으로 전환한다. 버튼을 여러 번 눌러도 이동과 타이머가 중복 실행되지 않게 한다.

**3. 직접 둘러보기**

| 환경 | 이동 | 둘러보기 |
| --- | --- | --- |
| 컴퓨터 | 방향키 또는 WASD | 장면을 마우스로 드래그해 시점을 돌리고, 휠로 거리를 조절한다. |
| 휴대전화 | 화면 아래의 가상 조이스틱 | 장면을 손가락으로 드래그해 시점을 돌린다. |

카메라는 인물을 따라간다. 벽·의자·제대는 통과하지 못하게 하고, 바닥 밖으로 떨어지지 않도록 이동 구역을 제한한다. 입력을 놓으면 인물은 멈춘다. 카메라가 지나치게 가까워지거나 벽 안으로 들어가는 것도 제한한다.

**4. 기도하기와 일어서기**

성당 안에서 ‘기도하기’를 누르면 이동이 멈추고 인물이 무릎을 꿇으며 주님의 기도 전문이 나온다. (수정) 기도 중에는 이동 입력을 무시한다. ‘일어서기’를 누르면 기도문을 닫고 다시 이동할 수 있다. 성당 밖에서는 기도 버튼 대신 ‘성당 안으로 들어가 기도해 보세요’라는 안내를 제공한다.

**5. 처음으로 돌아가기**

‘처음으로’를 누르면 자동 이동·기도 동작과 낭독을 즉시 멈추고, 인물·문·카메라를 초기 상태로 되돌려 마당의 시작 화면을 보여 준다. (수정)

**6. 배경음악과 소리 조절** (수정)

배경음악은 바흐 전주곡 C장조 BWV 846(바흐·구노 「아베 마리아」의 반주 부분)을 오르골 음색으로 연주한다. (수정) 녹음 음원 파일 없이 브라우저의 Web Audio 기능으로 음을 직접 만들어, 인터넷 없이 HTML 파일 하나로 동작하게 한다. (수정)

‘성당으로 들어가기’ 또는 ‘직접 둘러보기’를 처음 누를 때, 소리가 켜져 있으면 작은 소리로 서서히 시작하고 곡이 끝나면 처음부터 반복한다. (수정) 음악이 중복 재생되지 않게 한다. (수정) 화면 위쪽의 ‘소리 끄기’를 누르면 음악과 낭독을 멈추고, ‘소리 켜기’를 누르면 음악이 다시 들린다. (수정)

**7. 주님의 기도 낭독** (수정)

자동 입장이 끝나거나 ‘기도하기’를 눌러 기도 장면이 시작되면, 주님의 기도 전문을 소리 내어 천천히 읽어 준다. (수정) 녹음 파일 없이 브라우저에 내장된 음성 읽기 기능과 기기에 설치된 오프라인 한국어 음성을 사용한다. (수정)

낭독하는 동안 배경음악 소리를 줄이고, 낭독이 끝나거나 중단되면 소리가 켜진 경우 원래 음량으로 돌린다. (수정) ‘일어서기’나 ‘처음으로’를 누르면 낭독을 즉시 멈춘다. (수정) 소리를 꺼 둔 상태면 낭독하지 않는다. (수정) 기기에 오프라인에서 사용할 수 있는 한국어 음성이 없으면 낭독 없이 기도문 글자만 보여 준다. (수정)

### 필수 기능 확정 (수정)

| 기능 | 구현할 범위 |
| --- | --- |
| 단일 HTML 실행 | 화면·스타일·3D 표시·상호작용 코드를 한 파일에 포함한다. 외부 이미지·글꼴·모델·스크립트 서버에 연결하지 않는다. |
| 실제 3D 공간 표시 | 시점을 돌렸을 때 성당과 인물의 다른 면이 보이는 입체 공간을 표시한다. 사진 확대만으로 이동을 표현하지 않는다. |
| 두 가지 감상 방식 | 약 1분의 자동 입장과 인물을 직접 움직이는 자유 이동을 제공한다. |
| 인물 동작 | 걷기·정지·무릎 꿇기·일어서기를 구분해 표현한다. |

| 기도 화면 | 천주교 공식 기도문 ‘주님의 기도’ 전문을 문구를 바꾸지 않고 표시하고, 사용자가 끝내기 전까지 유지한다. (수정) |
| 시작 상태 복원 | ‘처음으로’를 누르면 진행 중인 동작이 겹치지 않고 시작 화면으로 돌아간다. |
| 컴퓨터·휴대전화 대응 | 마우스·키보드와 터치에 대응하며 인물·기도문·버튼이 잘리지 않게 배치한다. |
| 실행 불가 안내 | 브라우저에서 3D 표시를 시작할 수 없으면 빈 화면 대신 실행 환경을 확인하도록 안내한다. |
| 배경음악 | 바흐 전주곡 C장조 BWV 846을 Web Audio로 합성해 오르골 음색으로 연주한다. (수정) 두 시작 버튼 중 하나를 처음 누르면 작은 소리로 서서히 시작해 반복하고, 화면 위쪽의 소리 버튼으로 켜거나 끈다. (수정) |
| 주님의 기도 낭독 | 기도 장면 시작 시 브라우저 내장 한국어 음성 읽기로 주님의 기도를 천천히 낭독한다. (수정) 낭독 중 음악을 줄이고 끝나면 원래대로 돌리며, ‘일어서기’·‘처음으로’·소리 끄기 때 낭독을 멈춘다. (수정) 오프라인 한국어 음성이 없으면 낭독 없이 글자만 표시한다. (수정) |

## 필요한 자료

**확정:** 성당과 인물은 코드로 새로 만들고, 기도문은 새로 쓰지 않고 천주교 공식 기도문 ‘주님의 기도’ 전문을 사용한다. (수정) 글꼴은 기기에 설치된 기본 글꼴을 사용한다.

| 자료 | 출처·준비 방식 | 사용 권한·사용 범위 |
| --- | --- | --- |
| 참고 프롬프트 이미지 | 사용자가 제공한 `KakaoTalk_20261107_020751467.jpg` | 기능과 분위기를 이해하는 참고 자료다. 이미지 자체를 HTML 화면에 넣거나 함께 재배포하지 않는다. |
| 성당 마당·외관·내부 | 제작 과정에서 새로 작성하는 3D 도형과 색상 | 외부 사진·건축 도면·유료 모델을 복사하지 않는다. 실제 성당의 정밀 복원이나 공식 자료로 표시하지 않는다. |
| 인물·걷기·기도 동작 | 이름·얼굴 없는 인물과 관절 움직임을 코드로 새로 제작 | 실존 인물의 사진이나 다른 작품의 캐릭터를 사용하지 않는다. |
| 기도문 | 한국천주교주교회의 공식 기도문(주님의 기도) (수정) | 출처를 밝히고 비상업적 학습용으로 문구를 바꾸지 않고 그대로 표시한다. (수정) |
| 성상(예수님상·성모님상) | 코드로 새로 만든 단순한 3D 형태 (수정) | 실제 성당의 성상이나 다른 작품을 복제하지 않는다. (수정) |
| 배경음악 | 바흐 전주곡 C장조 BWV 846(바흐·구노 「아베 마리아」의 반주 부분)을 Web Audio로 직접 합성하는 오르골 연주 (수정) | 작곡가 사후 오래되어 원곡의 저작권 보호기간이 끝난 곡을 사용한다. (수정) 녹음 음원 파일은 사용하지 않는다. (수정) |

| 사진·녹음 음원·영상·외부 3D 모델 (수정) | 기본 버전에 사용하지 않음 | 외부 사진·녹음 음원·영상·3D 모델은 사용하지 않는다. (수정) |

기도문 사용 확정: 천주교 공식 기도문 ‘주님의 기도’ 전문을 사용하며, 문구를 바꾸지 않고 그대로 표시한다. (수정)

3D는 브라우저의 WebGL 기능을 이용하는 것으로 확정한다. (수정) 외부 CDN에서 엔진을 불러오지 않는다. 추후 외부 라이브러리·모델·글꼴을 채택한다면 출처, 버전, 라이선스와 표시 의무를 이 표에 추가하고 실행에 필요한 코드를 HTML에 포함한다.

추후 사진을 추가할 경우 컴퓨터 파일 경로 대신 **https://로 시작하는 주소**를 사용하며 원출처·권리자·사용 허락·저작자 표시 조건을 기록한다. 인터넷 사진을 불러오는 변경은 오프라인 조건에 영향을 주므로 별도 결정한다.

## 완료 기준

아래는 구현 후 확인할 **완료 기준 확정**이다. (수정) 시간 허용 범위와 시험 화면 크기도 확정 수치다. (수정)

| 번호 | 실행 방법 | 통과 조건 |
| --- | --- | --- |
| C1 | 인터넷을 끊고 컴퓨터에서 HTML 파일 하나를 더블클릭한다. | 추가 파일 선택·로그인·API 키 없이 성당 마당과 시작 버튼이 나온다. 성당 마당 시작 화면에서 성모님상 동굴이 보인다. (수정) |
| C2 | ‘성당으로 들어가기’를 누르고 기다린다. | 바깥 → 문 열림 → 중앙 통로 → 무릎 꿇기 순서로 자동 진행한다. 페이지를 활성 상태로 둔 기준 55~65초 안에 기도 장면과 기도문이 나온다. |
| C3 | 자동 입장이 끝난 뒤 30초 더 기다린다. | 인물과 기도문이 유지되고 자동 반복하지 않는다. |
| C4 | ‘직접 둘러보기’를 선택하고 방향키 또는 WASD를 누른다. | 인물이 입력한 방향으로 이동하고 카메라가 따라간다. 키를 놓으면 멈춘다. 자동 진행 중 선택해도 현재 위치에서 전환된다. |
| C5 | 장면을 드래그하고, 컴퓨터에서는 휠도 움직인다. | 3D 공간의 다른 면이 보이도록 시점이 변하며, 정해진 범위 안에서 거리가 조절된다. |
| C6 | 벽·의자·제대를 향해 계속 이동한다. | 인물이 물체를 통과하거나 공간 밖으로 떨어지지 않는다. |
| C7 | 성당 안에서 ‘기도하기’를 누른 뒤 ‘일어서기’를 누른다. | 무릎 꿇기와 기도문이 나타난다. 일어서기를 누르면 기도문이 닫히고 다시 이동할 수 있다. |
| C8 | 자동 이동·직접 이동·기도 중 각각 ‘처음으로’를 누른다. | 마당의 시작 화면으로 돌아간다. 이후 다시 시작해도 인물 동작이나 타이머가 겹치지 않는다. |
| C9 | 컴퓨터 1440×900·1280×720, 휴대전화 세로 390×844·360×800 화면에서 연다. 크기는 CSS 픽셀 기준이다. | 가로 스크롤 없이 장면·버튼·기도문을 확인할 수 있다. 휴대전화에서 조이스틱으로 이동하고 손을 떼면 멈춘다. 기도 버튼을 터치할 수 있다. |
| C10 | 인터넷을 끊은 상태로 입장·이동·기도를 끝까지 실행한다. | 성당·인물·기도문이 표시되며 외부 사진·글꼴·모델·영상·서버 연결을 요구하지 않는다. 음악과 낭독도 인터넷 없이 동작한다. (수정) 오프라인 한국어 음성이 없는 기기는 낭독 없이 기도문 글자만 표시한다. (수정) |
| C11 | ‘성당으로 들어가기’를 누른 뒤 ‘소리 끄기’를 누르고, 다시 같은 소리 버튼을 누른다. (수정) | 오르골 음악이 시작된다. (수정) ‘소리 끄기’를 누르면 음악이 멈추고, 다시 누르면 다시 들린다. (수정) |
| C12 | 오프라인 한국어 음성이 있는 기기에서 기도 장면을 시작한 뒤, 낭독 중 ‘일어서기’를 누른다. (수정) | 주님의 기도 낭독이 나오고 음악 소리가 작아진다. (수정) 낭독 중 ‘일어서기’를 누르면 낭독이 즉시 멈춘다. (수정) |
| C13 | 컴퓨터 1440×900 화면에서 자동 입장의 마지막 기도 장면을 확인한다. (수정) | 무릎 꿇은 인물, 예수님상이 달린 십자가, 성모님상, 기도문이 한 화면에 함께 보인다. (수정) |

## 추가 기능

다음은 **선택 제안**이다. 기본 버전의 완료 판정에는 포함하지 않는다.

| 추가 기능 | 선택 시 제공할 동작 | 필요한 조건 |
| --- | --- | --- |
| 자동 입장 일시정지 | ‘일시정지’를 누르면 진행이 멈추고 ‘계속’을 누르면 이어진다. | 기본 자동 입장 흐름을 확장한다. |
| 움직임 줄이기·글자 확대 | 배경 이동을 줄이거나 기도문을 크게 표시한다. | 기본 조작과 별도 설정을 제공한다. |
| 여러 접속자가 함께 머물기 | 실제로 접속한 사람들의 인물을 같은 공간에 표시한다. | 실시간 서버와 인터넷 연결이 필요하다. 현재의 서버 없는 오프라인 조건과 달라 별도 온라인 서비스 기획이 필요하다. |

실제 접속자가 없는 상태에서 임의의 인물을 다른 접속자인 것처럼 표시하지 않는다.

## 한계 및 비목표 (3가지)

다음은 **범위 확정**이다. (수정)

1. **실제 명동성당의 정밀 복원은 목표로 하지 않는다.** 성당에서 영감을 받은 공간과 기도 분위기를 표현한다. 실제 치수·좌석·장식·출입 경로와 차이가 있을 수 있으며, 공식 관람 안내나 현장 답사 자료로 사용하지 않는다.
2. **기본 버전은 혼자 사용하는 공간이다.** 다른 접속자와의 실시간 동기화·채팅·회원가입·개인정보 수집·신자 모집 관리는 넣지 않는다. 로그인·서버·API 키·챗봇·AI 기능도 기본 범위에 포함하지 않는다.
3. **모든 기기의 동일한 3D 성능과 파일 미리보기 실행은 보장하지 않는다.** WebGL을 지원하는 브라우저를 대상으로 한다. 기기 성능에 따라 입체 표현과 그림자를 단순화할 수 있다. 휴대전화는 단순 문서 미리보기가 아닌 HTML의 JavaScript 실행을 지원하는 환경에서 검증한다. 낭독 목소리는 기기에 설치된 음성에 따라 다르며, 사람이 녹음한 목소리가 아니다. (수정) 휴대전화 기종에 따라 한국어 낭독이 되지 않을 수 있다. (수정)

## 검증 방법 (비교 대상과 절차)

**검증 방법 확정: 같은 HTML 파일을 컴퓨터와 휴대전화에서 실행하며 기획서와 대조하는 수동 시나리오 검증 1가지.** (수정)

- **비교 대상:** 이 문서의 공간 구성·동작 순서·완료 기준 C1~C13과 실제 HTML에서 보이는 화면·입력 반응·진행 시간. (수정)
- **참고 이미지의 역할:** 작은 인물, 공간 탐색, 기도 행동, 차분한 화면 구성의 방향만 참고한다. 사찰의 종교 요소나 화면을 그대로 복제하는 기준으로 사용하지 않는다.
- **환경:** C9의 화면 크기와 실제 휴대전화의 터치 조작. 컴퓨터의 화면 크기 모사와 실제 기기의 결과를 구분해 기록한다.

절차:

1. HTML 파일 하나를 준비하고 인터넷을 끊는다. 직접 열어 마당과 시작 버튼이 나오는지 확인한다.
2. ‘성당으로 들어가기’를 누르는 순간 시간을 잰다. 페이지를 화면 앞에 둔 상태로 네 장면의 순서와 소요 시간을 기록한다.
3. 마지막 기도 장면을 30초 더 지켜본 뒤, 일어서기와 직접 이동을 확인한다.
4. 처음으로 돌아가 ‘직접 둘러보기’를 선택한다. 키보드 이동·시점 회전·거리 조절·벽과 의자 충돌을 확인한다.
5. 성당 안에서 기도하기·일어서기를 반복하고, 자동 진행 중 직접 이동으로 바꾸는 동작도 확인한다.
6. 각 상태에서 ‘처음으로’를 누른 후 다시 시작해 동작이 중복되지 않는지 확인한다.
7. 휴대전화 화면에서 같은 절차를 진행한다. 조이스틱·드래그·기도 버튼 터치와 화면 잘림을 확인한다.
8. 화면에 표시된 주님의 기도를 한국천주교주교회의 공식 기도문과 한 줄씩 대조해 글자가 빠지거나 바뀐 곳이 없는지 확인한다. (수정)
9. C1~C13별로 ‘통과/실패, 관찰 결과, 실행 환경’을 기록한다. (수정) 실패한 부분을 수정한 뒤 같은 시나리오로 재확인한다.

현재는 기획 단계이며, 위 내용은 HTML 제작 후 수행할 검증 계획이다.
